# peg.markets top-10 design challenge — entry brief for Codex

Copy this whole file into Codex. You are joining a running challenge: ten directions already exist at
https://decouple.co/design/peg-markets/studies/. Your job is **one original direction** that would earn a place in the
top ten, built in the same format, on the same framework, from the same fixture. Do not stop at a plan or a moodboard:
propose, choose, build, verify, publish, report.

Repository: `~/workspace/peg-markets` (`decoupleco/peg-markets`). Work on a new branch `codex/peg-markets-entry` cut
from `design/peg-markets-wireframe`. Write only inside `design/peg-markets/studies/entrants/codex-<slug>/`. Do not edit
the ten studies, `build.js`, `fixture.js`, `check.mjs`, the wireframe or anything outside that folder.

## 2. Find the gap before you design

Each existing direction is five structural choices plus a theme:

| axis | values already used |
| --- | --- |
| navigation | week strip + tabs, segmented top, breadcrumbs, menu rail, bottom tabs, status strip, step header |
| lead block | fee gauge, big quote, ledger statement, balance, collateral ladder, meters, task list |
| market row | flow gauge, rate board, ledger lines, dense table, 2×2 cards, collateral ladder, three meters |
| chart | quote + oracle overlay, fee-over-oracle spread bars, collateral areas, small multiples, oracle fee band, single spark |
| action | sticky dock, inline, bottom sheet, desktop side ticket |

Write three one-sentence theses for genuinely new directions. Pick the strongest in at most 100 words, naming the
weakness in the current ten it answers (examples you may take or reject: no direction leads with the currency itself
rather than the market; no direction treats settlement as a timeline; none designs for a borrower watching health
first; none uses a calendar or a map of IOUs between markets). Your direction must differ from **every** existing one
in at least three of the five axes; introduce at least one value not in the table above. Write the five choices in your
page header, and the minimum distance to the ten.

## 3. What to build

One self-contained HTML file, `entrants/codex-<slug>/index.html`, generated by `entrants/codex-<slug>/build.js` (Bun),
with the same seven screens the ten use:

| id | canvas | screen |
| --- | --- | --- |
| M01 | phone 390 × 844 | Swap · ready (100.0000 pegUSD → 91.421774 pegEUR) |
| M02 | phone | Markets (all four) |
| M03 | phone | pegUSD market detail |
| M04 | phone | Mint (deposit 100.0000 sUSDS, borrow 80.0000 pegUSD) |
| M05 | phone | Channel detail (AUDM / pegAUD) |
| D01 | desktop, full width | Markets workspace |
| D02 | desktop, full width | Weekly settlement (buffer) |

Use the μi layers exactly as the ten do: `layer('reset'|'theme'|'base')`, `prune(layer('comp'), BODY)`,
`prune(COMPOSITES)`, then your study CSS, then one theme block that sets the μi tokens (`--n0…--n4`, `--fg…--fg3`, `--ac`,
`--on-ac`, `--ac-s/-b/-f`, `--ok-*`, `--wa-*`, `--c1`, radii, `--disp`, `--numf`). Import every figure from
`../../../fixture.js`; never type a derived number by hand. Keep the gallery chrome (back link, thesis, axes, screen
links, `.board:has(.screen:target)` focus) visually distinct from the product screens.

## 4. Acceptance — every item is a gate, report each with its evidence

1. **Rules 1–12 of `docs/DESIGN-CHALLENGE.md` §2.** In particular: composition not palette; spec words and the §4 fixed
   strings verbatim; tabular lining figures for every number; accent off red and amber, health below 1.00 is `--no`,
   locked collateral is `--wa`; unavailable is never zero; quote and oracle drawn as real series in sUSDS per peg;
   one primary action per screen; no dialog that cannot close on Escape.
2. **Fixture closes.** `bun design/peg-markets/check.mjs design/peg-markets/studies/entrants/codex-<slug>/index.html`
   exits 0, and your page shows at least 14 of the 18 derived figures.
3. **Contrast.** Every pair fg/n0, fg2/n0, fg3/n0, fg3/n1, fg2/n1, on-ac/ac, ac-f/n0, ac-f/ac-s, ok-f/n0, wa-f/n0
   reaches 4.5:1; print the worst.
4. **Static and small.** No `<script>` on the page; zero external resources; ≤ 40,000 B brotli (quote brotli and gzip;
   the edge serves gzip over HTTP/2); CLS 0 at load measured in a real browser; no element wider than its phone frame.
5. **Distance.** Your five axes against each of the ten in `prompts.json`; minimum ≥ 3; print the table.
6. **Honesty.** Not tested: physical devices, screen readers, real users. Say so.

Write `entrants/codex-<slug>/verification.json` with the numbers for items 2–5, and a `README.md` (thesis, the three
alternatives you rejected and why, the five axes, the distance table, what you would change in round 2).

Do not push to a default branch. Do not change the shared fixture to make a number fit; if a figure seems wrong,
report it instead.
