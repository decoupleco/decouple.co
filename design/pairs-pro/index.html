Pairs.pro, in frames

The refresh of the Pairs.pro web app as a wireframe sheet: the pools list, the pool view with its price, depth and performance charts and the Advance tables, the account view and the admin view, drawn for each role in the μi Sharp outline. Every frame has an id that the user-story spec cites (pairs-pro/docs/refresh-user-stories.md); the same sheet prints to refresh-wireframe.pdf.

Controls hold a static state: period, chart type and tabs press but do not switch data. Charts read out on hover or with ← →. The strategy bands cover the whole history — dashed where they are projected from the current config, solid where the keeper ran them. Every number carries source · block · kind on hover; the sheet draws the kind where it changes the reading.
