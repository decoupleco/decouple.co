01 / Currency language

A code is a unit.
A token is an asset.

USDUS dollar unit
pegUSDProtocol token
sUSDSCollateral token
AUDMIssuer token

Show the actual asset symbol in amounts and reviews. Use a currency name as context, not as a replacement for token identity.

No flag is required. Currency minor units are not token decimals. A currency code alone does not prove a peg, a chain, an address or redemption rights.

Currency-code reference: SIX / ISO 4217. Protocol token examples are illustrative, not ISO currency codes.

02 / Simple technical English

Seven jobs.
Plain words.

Short active sentences. One term per idea. Not a claim of certified STE compliance.

S1 / Compare first

I want to compare markets before I connect a wallet.

Show available collateral and utilization. Do not require a wallet to browse.

M02 · D01
S2 / Know the swap

I want to know what I pay and the minimum I receive.

Name the actual tokens. Show minimum received, fee and quote state before signing.

M01
S3 / Borrow with context

I want to see how new debt changes my health.

Separate the loan from LP shares. Show collateral, debt and health before and after.

M03 · M04
S4 / Supply liquidity

I want to add liquidity without confusing it with my loan.

Switch the summary and form together. Distinguish marked LP value from available withdrawal cash.

M03
S5 / Inspect my channel

I want to see my range, both token amounts and each collectible amount.

Range status describes this position. Do not call every collectible amount a fee.

M05
S6 / Recover safely

I want to know what failed and how to continue.

Show expired, disconnected and partial-failure states. Never repeat a confirmed approval automatically.

M01 · M04
S7 / Check settlement

I want to check the batch before I run settlement.

Show source and completeness. Keep execution disabled when a complete, balanced batch is unavailable.

03 / UX review

Less theatre.
More confidence.

Identity

Replace currency-only token labels and flags with actual assets plus a clear currency unit.

Two tasks

Separate Mint debt and LP shares. Change the summary and form together.

Honest numbers

Show physical available/locked collateral. No invented APY, chart history or complete settlement.

Before signing

Show minimum received and before/after health. Use the real execution plan for approvals.

Accounting

LP value includes fees. Collectible channel tokens may include principal. No double counting.

Recovery

Explain expired quotes, wrong network and partial failures. Keep completed approvals visible.

Evidence, limitations and contribution format
