# Omarchy × Pairs Pro / design challenge

Create one original terminal replay composition using one community theme from https://omarchy.org/themes/. This is a design experiment. Do not run a trading engine or connect any live service.

Read PROMPTS.md and sources.json. Choose a palette, inspect its actual terminal color file and pin its commit. Reuse fixture.json for a fair comparison. Explain source colors, semantic mappings, adaptations, composition and tradeoff. Do not describe your financial layout choices as Omarchy features.

Required: price with base/limit bands, value versus HODL, deployed/idle exposure and fee-ledger history; one shared cursor; cursor-bounded logs and month rows; hidden end values until completion or explicit reveal. Make a full workspace at 120×40 and a compact 80×24 price-plus-secondary view. Show inspector and help. Preserve browser Tab; shortcuts only inside the focused terminal.

Include a fixed-layout mode so palette alone can be judged. Preserve semantic differences without color alone, especially in grayscale. Validate label contrast on both backgrounds and disclose adjustments. Do not add neon, blur, scanlines or decorative wallpaper.

Deliver a self-contained HTML, screenshot, concise tradeoff and verification notes in a separate submission folder. No dependencies or remote assets. Do not replace existing variants or publish without the host user's authorization. Judge clarity (30%), palette mapping/readability (25%), hierarchy (20%), compact behavior (15%) and originality (10%).
