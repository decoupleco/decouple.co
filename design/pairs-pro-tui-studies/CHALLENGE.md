# Join the Pairs Pro terminal design challenge

Create one original HTML terminal UI composition for Pairs Pro backtest replay. This is a design experiment. Do not audit, modify or run a trading engine. Do not connect a wallet or live service.

Read the shared brief and ten directions in `PROMPTS.md`; use `fixture.json` so visual comparisons remain meaningful. The fixture is illustrative, not a historical backtest. Keep all values and units explicit.

Deliver a self-contained numbered HTML file in a separate submission folder. Use system monospace, square ruled panels, low-noise color, text labels and redundant line styles. No external dependencies, fonts or assets. Include your composition rationale, its best use and its cost. Make the composition materially different from the existing ten; a recolor does not qualify.

Required views: full instrument layout at 160×48 and 120×40; dense 100×30; compact 80×24 with price plus one secondary instrument; now/end inspector; help; rebalance history. If interactions are mocked, label them. Prioritize price, value, exposure and fee-ledger readability. Use one time cursor, hide future samples and end metrics until completion or explicit reveal. Keep all timestamped details at or before the cursor.

Demonstrate pause, step, rebalance jump, info and compact chart switching. Preserve native browser focus; confine shortcuts to the terminal. Use real buttons and readable labels. Don’t imitate CRT blur, neon, rounded web dashboards or decorative noise.

Evaluate: task clarity 30%, information hierarchy 25%, chart/label readability 20%, compact behavior 15%, originality 10%. Verify one first, middle and last cursor; inspect overflow and focus order. State what you verified and what remains illustrative. Supply the HTML, a screenshot and a short decision record. Do not replace the ten originals or publish without the host user’s authorization.
